PhotoForge Privacy Policy

Effective Date: August 2026

1. Absolute Local Privacy & Zero Telemetry

PhotoForge does not collect, store, transmit, or monetize any personal information, telemetry, analytics, device identifiers, or crash logs. All photo analysis and metadata operations run strictly on your local machine.

2. Zero Internet Access Required

The PhotoForge Android application deliberately requests zero network permissions (android.permission.INTERNET is not declared). The Windows application does not make outbound internet requests except when you manually click "Check for Updates" to query the latest release version on GitHub.

3. Source File Immutability

PhotoForge adheres to invariant INV-01: original camera photos are opened in strictly read-only mode and are never modified in place.

4. Granular GPS Privacy Controls

PhotoForge allows users to retain exact GPS coordinates, fuzz coordinates to a ~1 km radius buffer for privacy, or remove location tags entirely.

5. Contact & Open Source

PhotoForge is open source software. The complete codebase is publicly auditable at github.com/ramanacr/photo-forge.
