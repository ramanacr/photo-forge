# PhotoForge Roadmap & Commercialization

## Phase 0 — Foundation
Deliver:
- core domain model
- metadata abstraction
- marker specification
- matching prototype
- format sniffing
- test corpus
- dependency/legal review

Exit:
- architecture stable
- 100+ fixture tests
- source immutability proven

## Phase 1 — MVP
Deliver:
- JPEG/PNG/WebP/TIFF/HEIC
- restore metadata
- GPS
- matching
- manual override
- batch
- verification
- HEIC conversion
- Windows GUI
- Android basics
- CLI prototype

Business goal:
Validate that the core pain is real and that users trust the results.

## Phase 2 — Pro
Deliver:
- advanced profiles
- larger scale
- richer audit
- better matching
- robust CLI
- professional reports
- DNG metadata workflows
- Windows Explorer shell
- portable mode

Monetization:
- one-time license or subscription for Pro
- preserve a useful free tier

## Phase 3 — Professional Workflow
Deliver:
- RAW metadata support
- studio/batch presets
- job history
- reusable workflows
- validation against independent metadata readers
- improved HEIC quality controls

Customers:
- photographers
- studios
- media professionals

## Phase 4 — Platform / SDK
Deliver:
- embeddable PhotoForge Engine
- documented API
- bindings
- partner integration
- enterprise offline deployment

Revenue:
- SDK licensing
- enterprise licensing
- support/SLA

## Phase 5 — Enterprise
Potential:
- policy bundles
- fleet deployment
- enterprise signing
- local audit exports
- air-gapped deployment
- role-based configuration at management layer

## Commercial moat

The strongest moat is not "EXIF copying."

It is:
1. highly reliable original/edited matching,
2. metadata merge correctness,
3. cross-platform native engine,
4. verification,
5. migration idempotency,
6. privacy/offline trust,
7. compatibility corpus,
8. automation/CLI/SDK.

## Competitive positioning

Avoid:
> "Another EXIF editor"

Prefer:
> "The metadata continuity tool for edited photos."

## Pricing hypotheses

Validate rather than assume:
- Free: limited batch / standard restoration
- Pro: roughly consumer utility price point
- Studio/Business: higher annual license
- Enterprise/SDK: negotiated

Do not build the entire product around subscription-only economics before validating willingness to pay.
