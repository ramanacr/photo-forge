# PhotoForge Visual Identity & Branding Guide

Official brand identity guidelines, color palettes, typography, and asset inventory for PhotoForge across Windows, Android, and Web platforms.

---

## 🎨 Color Palette

| Token Name | Hex Code | RGB | Role |
|---|---|---|---|
| **Accent Primary (Cyan)** | `#00B4D8` | `rgb(0, 180, 216)` | Primary branding, buttons, highlights, active states |
| **Accent Success (Neon Green)** | `#4ADE80` | `rgb(74, 222, 128)` | Invariant status badges, verified indicators, success state |
| **Background Dark (Obsidian)** | `#121212` | `rgb(18, 18, 18)` | Root application background |
| **Surface Dark (Graphite)** | `#1E1E1E` | `rgb(30, 30, 30)` | Cards, panels, navigation sidebar |
| **Surface Darker** | `#181818` | `rgb(24, 24, 24)` | Input controls, table rows |
| **Border Dark** | `#2A2A2A` | `rgb(42, 42, 42)` | Borders, separators, outlines |
| **Text Primary** | `#FFFFFF` | `rgb(255, 255, 255)` | High-contrast headlines and body text |
| **Text Secondary / Muted** | `#AAAAAA` | `rgb(170, 170, 170)` | Subtitles, helper text, timestamps |

---

## 🔤 Typography

- **Windows Desktop:** `Segoe UI Variable Text`, `Segoe UI`, `sans-serif`
- **Android:** `Roboto`, `Google Sans`, `system-ui`
- **Terminal CLI:** `Consolas`, `Cascadia Code`, `Fira Code`
